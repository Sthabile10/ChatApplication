# Java User Management & Authentication System

A Java-based application implementing user registration, secure login authentication, and modular unit testing with JUnit 4. Built as part of an IT software development assessment.

---

## Project Overview

This project provides a robust backend implementation for user account management. It features input validation, credential verification, and automated test coverage to ensure system reliability and security.

### Key Features
* User Registration: Validates and stores user credentials according to system requirements.
* Authentication Service: Verifies login credentials against registered user records.
* Automated Unit Testing: Full JUnit 4 test suite covering successful authentication, invalid credentials, and boundary test cases.

---

## Tech Stack & Tools

* Language: Java (JDK 8 or higher)
* IDE: NetBeans / IntelliJ IDEA / Eclipse
* Testing Framework: JUnit 4
* Version Control: Git & GitHub
